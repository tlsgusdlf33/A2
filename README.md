# autopub — 트렌드 기반 자동 발행 파이프라인

지금 가장 이슈되는 주제를 자동으로 찾아서
**티스토리 블로그 글**과 **세로형 숏폼 영상(유튜브 쇼츠 + 틱톡)** 을 만들고 발행합니다.

```
트렌드 수집 → 주제 선정 → LLM 생성 → (블로그) HTML 발행
                                  └ (숏폼) 카드 렌더 → 카드별 TTS → ffmpeg → 업로드
```

## 숏폼 영상 스타일 3가지

`config.yaml` 의 `video.style` 로 고릅니다.

| 스타일 | 화면 | 적합한 주제 |
|---|---|---|
| **`news`** (기본) | 내용과 관련된 이미지를 AI로 생성해 방송 화면으로 구성. 못 만든 장면은 **AI 앵커**가 전달 | 일반 뉴스·이슈 |
| `card` | 단색 배경 + 직접 그린 카드 카운트다운 | 주식·통계처럼 도해가 핵심인 주제 |
| `broll` | 스톡 영상 + 흐르는 자막 | 초기 방식 (권장하지 않음) |

### news — 생성 이미지 + AI 앵커

```
 ┌─────────────────┐   ┌─────────────────┐   ┌─────────────────┐
 │   [AI 생성 영상]│   │   [AI 생성 영상]│   │   [AI 생성 영상]│
 │                 │   │                 │   │                 │
 │   AI 앵커       │   │  생성된 관련    │   │   AI 앵커       │
 │   (오프닝)      │ → │  이미지          │ → │  (이미지 실패 시)│
 │                 │   │                 │   │                 │
 │ [속보]          │   │ [3위]           │   │ [1위]           │
 │ ▌헤드라인       │   │ ▌헤드라인       │   │ ▌헤드라인       │
 │ ┌─ 설명 박스 ─┐ │   │ ┌─ 설명 박스 ─┐ │   │ ┌─ 설명 박스 ─┐ │
 │ NEWS ─ 티커 ──  │   │ NEWS ─ 티커 ──  │   │ NEWS ─ 티커 ──  │
 └─────────────────┘   └─────────────────┘   └─────────────────┘
```

항목마다 **내용과 관련된 이미지를 직접 생성**하고, 만들지 못한 항목만
AI 앵커 화면으로 대체합니다. 이미지 생성은 **키가 필요 없는 무료 엔드포인트**
(Pollinations)가 기본이고, Together AI·Cloudflare Workers AI 무료 티어로 교체할 수 있습니다.

> **진짜 text-to-video 는 무료로 돌릴 방법이 없습니다.** 대신 이미지를 생성해
> 느린 확대로 움직임을 줍니다. 뉴스 숏폼에서는 이 편이 자막 가독성도 좋고
> 실패 지점도 적습니다. 입 모양을 맞추는 립싱크(Wav2Lip 등)는 상용 이용이
> 제한된 라이선스가 많아 넣지 않았습니다.

### AI 앵커

앵커가 매번 다른 얼굴이면 채널로 보이지 않습니다. 그래서 **한 번 만들어 고정**합니다.

```bash
python -m autopub anchor --candidates 6    # 후보 6장 생성
python -m autopub anchor --pick assets/anchor/candidates/candidate_1137.jpg
```

`assets/anchor/anchor.jpg` 가 확정된 앵커입니다. 설정하지 않으면 첫 실행 때
`anchor_seed` 로 자동 생성되지만, **공개 발행 전에 반드시 직접 열어서 확인하세요.**

### ⚠️ AI 생성 고지는 자동으로 켜집니다

유튜브와 틱톡 모두 합성 콘텐츠 표시를 요구합니다. 무인 업로드라 사람이 매번
체크할 수 없으므로 코드가 자동으로 처리합니다.

- YouTube: `status.containsSyntheticMedia = true`
- TikTok: `post_info.is_aigc = true`
- 영상 화면 우상단에 `AI 생성 영상` 배지
- 설명란 첫 줄에 고지 문구

미표시 상태로 반복 업로드하면 채널 제재 대상이 되므로 끄지 마세요.

### 실존 인물은 그리지 않습니다

뉴스 주제에는 실존 인물이 섞여 있습니다. 그 사람의 모습으로 **실제로 일어나지 않은
장면**을 만들어 뉴스처럼 내보내는 것이 이 기능의 가장 큰 위험입니다.

그래서 장면 이미지 프롬프트에 사람(`person`, `politician`, `crowd`, `face` …)이
들어가면 **프롬프트를 버리고 앵커 화면으로 떨어뜨립니다.** 한글 프롬프트와
너무 짧은 프롬프트도 같은 처리를 합니다.

### card — 카운트다운 카드

카드 형식은 **카운트다운** 구조입니다. 스톡 영상 위에 자막을 얹는 방식이 아니라,
단색 배경에 직접 그린 카드를 한 장씩 넘깁니다.

```
 ┌─────────────────┐   ┌─────────────────┐   ┌─────────────────┐
 │  절대 하면      │   │      3위        │   │      1위        │
 │  안되는 4가지   │   │    슈팅스타     │   │    흑삼병       │
 │                 │ → │  ┌───────────┐  │ → │  ┌───────────┐  │
 │ [4위][3위][2위] │   │  │ 캔들 차트 │  │   │  │ 캔들 차트 │  │
 │      [1위]      │   │  └───────────┘  │   │  └───────────┘  │
 │                 │   │ ┌─ 설명 박스 ─┐ │   │ ┌─ 설명 박스 ─┐ │
 └─────────────────┘   └─────────────────┘   └─────────────────┘
      인트로               항목 카드              1위 공개
```

이 방식을 택한 이유:

- **화면과 주제가 항상 일치합니다.** 스톡 b-roll 은 아무리 검색어를 잘 짜도
  "아무 영상에나 자막 얹은 티"가 납니다.
- **채널 고유의 톤이 생깁니다.** 배색과 레이아웃이 매번 같아서 피드에서 알아봅니다.
- **끝까지 봅니다.** 1위를 마지막에 공개하는 역순 카운트다운이라 이탈이 줄어듭니다.
- **카드마다 그 카드의 내레이션을 따로 합성**하므로 화면 전환과 말이 정확히 맞습니다.
- **외부 API 가 전혀 필요 없습니다.** 스톡 키 없이도 품질이 그대로입니다.

배색은 `video.cards.theme` 에서 `cream · mint · lemon · sky · charcoal` 중 선택합니다.

## 먼저 알아야 할 3가지 제약

무료로 돌리는 것이 목표라서, 플랫폼이 실제로 허용하는 한계를 그대로 반영했습니다.
**여기를 건너뛰면 반드시 막힙니다.**

### 1. 티스토리 — Open API가 종료되었습니다

카카오는 티스토리 Open API를 **2024년 2월까지 순차 종료**했습니다.
글 작성·수정·첨부 API가 전부 사라져서, 공식 API로 글을 올리는 방법은 **현재 존재하지 않습니다**.

그래서 이 프로젝트는 **Playwright 브라우저 자동화**로 처리합니다. 사람이 하는 것과 같은 순서로
로그인된 브라우저에서 에디터를 조작합니다. 이 방식의 현실적인 한계는 이렇습니다.

- 티스토리가 에디터 UI를 바꾸면 선택자가 깨질 수 있습니다 (`src/autopub/publishers/tistory.py` 상단의 선택자 목록만 고치면 됩니다)
- 카카오 로그인에 2단계 인증·캡차가 붙으면 자동 로그인이 막힙니다 → `scripts/tistory_login.py`로 **한 번 수동 로그인**해서 세션을 저장해 두는 방식을 권장합니다
- 저장된 세션은 영구하지 않습니다. 만료되면 다시 로그인해야 합니다
- 자동화 도구 사용은 서비스 약관상 회색지대입니다. **본인 계정, 본인 책임으로 사용하세요**

### 2. 유튜브 — 하루 6개가 물리적 상한입니다

YouTube Data API v3의 무료 쿼터는 프로젝트당 **10,000 units/day**이고,
영상 업로드(`videos.insert`)는 **1회에 1,600 units**를 씁니다.

```
(10,000 − 예비 400) ÷ 1,600 = 6회/일
```

`config.yaml`에서 `youtube.daily_max`를 비워 두면 이 값을 **자동 계산**합니다.
더 큰 값을 적어도 쿼터상 불가능하므로 6으로 깎입니다 (경고 로그가 남습니다).
더 올리려면 Google Cloud 콘솔에서 쿼터 증설을 신청해야 하고, 심사를 거쳐야 합니다.

> 참고: API 프로젝트가 Google의 컴플라이언스 감사를 통과하기 전에는 업로드한 영상이
> 비공개로 잠길 수 있습니다. 첫 업로드 후 영상 공개 상태를 반드시 확인하세요.

### 3. 틱톡 — 심사 전에는 비공개로만 올라갑니다

Content Posting API는 무료지만:

- 앱이 **심사(audit)를 통과하기 전에는 `SELF_ONLY`(비공개)로만** 게시됩니다.
  공개 발행을 하려면 TikTok 개발자 포털에서 Content Posting API 심사를 신청해야 합니다.
- 사용자 토큰당 **6 requests/분**
- 계정당 일일 상한이 있습니다(정확한 수치는 비공개, 대략 15~25건 수준). 기본값을 **10건**으로
  보수적으로 잡아 두었습니다.

이 프로젝트는 `creator_info/query`로 **실제 허용된 공개 범위를 먼저 조회**한 뒤,
요청한 값을 쓸 수 없으면 자동으로 허용된 값으로 낮추고 경고를 남깁니다.

## 하루 최대 발행 횟수 (기본값)

| 플랫폼 | 기본 한도 | 근거 |
|---|---|---|
| 티스토리 | **8건/일** | API 제한은 없지만 과다 발행은 저품질 블로그 판정 위험. 실전 권장 상한 |
| 유튜브 쇼츠 | **6건/일** | 무료 쿼터에서 자동 계산 (10,000 ÷ 1,600) |
| 틱톡 | **10건/일** | 계정 일일 상한 아래로 보수적 설정 |

모두 `config/config.yaml`에서 숫자만 바꾸면 조정됩니다.
단, 유튜브는 쿼터를 넘는 값을 넣어도 자동으로 깎입니다.

**한 번 실행에 1건씩** 발행합니다. 하루 최대 횟수는 크론이 하루에 여러 번 도는 것으로 채웁니다.
이렇게 해야 발행 간격(`min_gap_minutes`)이 지켜지고, 한 번에 몰아 올려서 스팸으로 판정될 위험이 사라집니다.

## 무료 스택

| 역할 | 사용 도구 | 비용 |
|---|---|---|
| 트렌드 수집 | Google Trends RSS, Google News RSS, YouTube `mostPopular`(1 unit) | 무료 |
| 글·대본 생성 | **Gemini 무료 티어** (기본) / Groq·OpenRouter 무료 모델 / Claude(유료) | 무료 |
| 음성 합성 | **edge-tts** (Microsoft Neural 한국어 음성) | 무료 |
| 자막 | edge-tts WordBoundary → ASS 번인 (STT 불필요) | 무료 |
| 이미지 생성 | Pollinations (키 불필요) / Together AI / Cloudflare Workers AI | 무료 |
| 카드 그래픽 | Pillow 로 직접 렌더링 (캔들차트·막대그래프 포함) | 무료 |
| 배경 영상·사진 | Pexels / Pixabay API *(broll 스타일에서만)* | 무료 |
| 영상 합성 | ffmpeg | 무료 |
| 스케줄러 | GitHub Actions 크론 | 공개 레포는 무료 |

> ⚠️ **비공개 레포는 Actions 분(minutes)이 과금됩니다.** 무료 2,000분/월 기준으로
> 하루 14회(블로그 8 + 숏폼 6) × 평균 5분 ≈ 월 2,100분이라 초과합니다.
> **공개 레포로 두거나**(크론 무제한 무료), 집 PC·라즈베리파이의 cron으로 돌리세요.

**품질을 최대로 올리고 싶다면** `.env`에서 `LLM_PROVIDER=anthropic`으로 바꾸세요.
Claude Opus 5가 본문과 대본을 쓰며, 이 경우만 유료입니다(그 외 모든 구성요소는 계속 무료).

## 빠른 시작

```bash
# 1) 설치
pip install -r requirements.txt
python -m playwright install chromium
sudo apt install ffmpeg fonts-noto-cjk     # macOS: brew install ffmpeg

# 2) 설정
cp .env.example .env    # 키 채우기

# 3) 점검 — 빠진 것을 먼저 알려줍니다
python -m autopub doctor

# 4) 지금 뜨는 주제 확인 (키 없이도 동작)
python -m autopub trends

# 5) 발행 없이 결과물만 만들어 보기
python -m autopub blog   --dry-run     # out/*.html 생성
python -m autopub shorts --dry-run     # work/*/video.mp4 생성

# 6) 실제 발행
python -m autopub blog                 # 티스토리 1건
python -m autopub shorts               # 쇼츠 1건 → 유튜브 + 틱톡
python -m autopub status               # 오늘 사용량 / 잔여 한도
python -m autopub anchor               # AI 앵커 초상 확인/생성
```

각 플랫폼 인증 설정은 **[SETUP.md](SETUP.md)** 에 단계별로 정리해 두었습니다.

## 품질을 위해 넣은 장치들

무작정 LLM에 맡기면 "AI가 쓴 티가 나는 글"과 "환각"이 나옵니다. 그래서:

- **근거 고정** — 수집한 실제 기사 제목·요약을 프롬프트에 넣고, **근거에 없는 수치·날짜·발언을 만들지 말라**고 강제합니다. 근거 기사가 하나도 없는 주제는 아예 후보에서 제외합니다.
- **교차 검증 가중치** — 여러 소스(Google Trends + 뉴스 + 유튜브)에 동시에 뜬 주제일수록 점수가 누적되어 상위로 올라갑니다. 짧은 키워드("최예나")와 긴 헤드라인("최예나, 신곡 발표…")을 같은 사안으로 묶습니다.
- **노이즈 제거** — 모호한 영문 약어, 한국어 근거가 없는 동명이의 주제, 24시간 지난 주제, 차단 키워드(사건·사고·의혹 등 수익화 위험 주제)를 걸러냅니다.
- **정확한 자막 싱크** — STT 없이 edge-tts의 단어 경계 이벤트를 그대로 써서 자막을 끊습니다. 무료이면서 싱크가 정확합니다.
- **그래프 환각 차단** — LLM이 `bars` 그래프를 요청해도 값이 숫자가 아니거나 라벨 개수가 맞지 않으면 그래프를 포기하고 텍스트 카드로 떨어집니다. 지어낸 수치를 그럴듯한 그래프로 보여주는 것이 가장 위험합니다.
- **카드 여백 보존** — 펀치인 줌 상한을 5%로 묶어 카드 테두리가 잘리지 않게 했습니다(여백이 5.9%).
- **TTS용 텍스트 정제** — 이모지·마크다운 기호·괄호 설명을 제거합니다. 안 하면 TTS가 "별표 별표"라고 읽습니다.
- **길이 보정** — 대본이 60초를 넘으면 뒤쪽 장면부터 덜어내 쇼츠 규격을 지킵니다.
- **중복 방지** — 최근 7일 안에 쓴 주제는 플랫폼별로 다시 쓰지 않습니다.
- **외부 링크 nofollow** — 참고 자료 링크에 `rel="nofollow noopener"`를 붙여 스팸 신호를 피합니다.

```
  trends/       트렌드 수집·병합·필터 (Google Trends, 뉴스 RSS, 유튜브)
  llm/          LLM 공급자 추상화 (Gemini / Anthropic / OpenAI 호환)
  content/      프롬프트, 블로그 글 생성, 숏폼 대본 생성
  media/        이미지 생성(imagegen), 방송 레이아웃·AI 앵커(broadcast),
                카드 렌더링(cards/charts/fonts), TTS, 자막, ffmpeg 합성
  publishers/   티스토리(Playwright) / 유튜브(Data API) / 틱톡(Content Posting API)
  pipeline.py   오케스트레이션 (한 번 실행 = 1건 발행)
  state.py      발행 이력·일일 한도 (JSON, Actions에서 커밋되어 유지)
  cli.py        커맨드라인

scripts/        최초 1회 인증 도우미 (youtube_oauth / tiktok_oauth / tistory_login)
.github/workflows/   크론 스케줄러
config/config.yaml   모든 설정 (한도, 프롬프트 길이, 영상 규격 …)
```
